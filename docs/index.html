Installation

Install (macOS & Linux):Installer (macOS & Linux) : RecommendedRecommandé

$ curl -fsSL https://raw.githubusercontent.com/simple-edit-app/simpleedit/main/install.sh | bash

macOS — Homebrew:macOS — Homebrew :

$ brew install --cask simple-edit-app/tap/simpleedit

Linux — .deb (install):Linux — .deb (installer) :

$ curl -fsSL https://api.github.com/repos/simple-edit-app/simpleedit/releases/latest | sed -n 's/.*"browser_download_url": *"\([^"]*\.deb\)".*/\1/p' | xargs curl -fsSLO && sudo apt install ./simpleedit_*.deb

Linux — AppImage (install):Linux — AppImage (installer) :

$ curl -fsSL https://api.github.com/repos/simple-edit-app/simpleedit/releases/latest | sed -n 's/.*"browser_download_url": *"\([^"]*\.AppImage\)".*/\1/p' | xargs curl -fsSLO && chmod +x simpleedit-*.AppImage && ./simpleedit-*.AppImage

Portable — no installation needed. To add it to your app menu, move it into ~/.local/bin and drop a .desktop entry (or use a tool like AppImageLauncher). Portable — aucune installation requise. Pour l’ajouter à votre menu d’applications, déplacez-le dans ~/.local/bin et ajoutez une entrée .desktop (ou utilisez un outil comme AppImageLauncher).

Uninstall (macOS & Linux):Désinstaller (macOS & Linux) :

$ curl -fsSL https://raw.githubusercontent.com/simple-edit-app/simpleedit/main/uninstall.sh | bash

Detects how SimpleEdit was installed — Homebrew cask, .deb package or plain binary — and removes it. Your settings and session are left untouched — delete ~/.config/simpleedit and ~/.local/share/simpleedit (the session, which holds the text of your unsaved files) on Linux, or ~/Library/Application Support/simpleedit on macOS, to remove them too. Détecte le mode d’installation — cask Homebrew, paquet .deb ou binaire simple — et le supprime. Vos réglages et votre session sont conservés — supprimez ~/.config/simpleedit et ~/.local/share/simpleedit (la session, qui contient le texte de vos fichiers non enregistrés) sous Linux, ou ~/Library/Application Support/simpleedit sous macOS, pour les effacer aussi.

macOS — Homebrew (uninstall):macOS — Homebrew (désinstaller) :

$ brew uninstall --cask simpleedit

Also drop your settings: brew uninstall --zap --cask simpleedit Pour aussi supprimer vos réglages : brew uninstall --zap --cask simpleedit

Linux — .deb (uninstall):Linux — .deb (désinstaller) :

$ sudo apt remove simpleedit

No apt? Use sudo dpkg -r simpleedit instead. Pas d’apt ? Utilisez sudo dpkg -r simpleedit à la place.

Linux — AppImage (uninstall):Linux — AppImage (désinstaller) :

$ rm -f simpleedit.AppImage ~/.local/bin/simpleedit.AppImage ~/.local/share/applications/simpleedit.desktop

Removes the AppImage from the current directory and, if you integrated it, from ~/.local/bin and your app menu. Supprime l’AppImage du dossier courant et, si vous l’aviez intégré, de ~/.local/bin et de votre menu d’applications.
